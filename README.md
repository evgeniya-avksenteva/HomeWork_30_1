# Онлайн-курсы — Проект

Приложение для сайта онлайн-обучения. 
Зарегистрированный пользователь может оплачивать интересующие его курсы, а также просматривать список своих курсов и уроков.

Запуск проекта через Docker Compose

Предварительные шаги:

- Скопируйте файл .env.example в .env и заполните необходимые переменные окружения (например, пароли, ключи API, настройки базы данных и т.п.): cp .env.example .env
- Убедитесь, что Docker и Docker Compose установлены и запущены на вашей машине.
- Запуск

- Для запуска всех сервисов (backend, PostgreSQL, Redis, Celery, Celery Beat) выполните команду: docker-compose up --build Параметр --build гарантирует, что все образы будут пересобраны.

- Остановка

- Для остановки сервисов используйте: docker-compose down

Проверка работы сервисов

- Backend: открыть в браузере http://localhost:8000. Вы должны увидеть приветственную страницу или API документацию.
- PostgreSQL: убедитесь, что контейнер db запущен:
- docker-compose ps
- Redis: проверьте логи контейнера Redis:
docker-compose logs redis
Celery: проверьте, что воркер Celery запущен и без ошибок:
- docker-compose logs celery
Celery Beat: проверьте работу планировщика задач:
- docker-compose logs celery-beat


# Настройка и деплой проекта

## Настройка удаленного сервера

1. Обновите систему и установите необходимые пакеты:
-  Python 3.9 и выше.
-  Django версии 3.2.
-  Gunicorn и Nginx для обработки запросов.

2. Настройте SSH-доступ:
- Настройте SSH-доступ с использованием SSH-ключей для повышения безопасности.
- Закройте все ненужные порты, оставив открытыми только те, которые необходимы 
(например, 80 для HTTP и 443 для HTTPS).
- Установите и настройте Supervisor для автоматического перезапуска приложения при изменениях.

3. Передайте проект на сервер:
- Склонируйте репозиторий: `git clone https://github.com/вevgeniya-avksenteva.git`
- Выполните миграции базы данных с помощью команды 
```python manage.py migrate```

- Войдите в папку и создайте виртуальное окружение:
  ```
  python3 -m venv venv
  source venv/bin/activate
  pip install -r requirements.txt
  ```
4. Настройте `.env` файл с секретами и параметрами проекта.

5. Настройте Gunicorn и Supervisor:
- Создайте конфигурацию Supervisor для управления Gunicorn.
- Запустите Supervisor.

6. Настройте nginx для проксирования.

## Настройка GitHub Actions workflow

1. В репозитории создаете файл `.github/workflows/ci.yml` .

2. В настройках репозитория в Secrets добавьте:
- 'API_KEY_STRIPE'
- 'DEPLOY_DIR'
- 'DOCKER_HUB_ACCESS_TOKEN'
- 'DOCKER_HUB_USERNAME'
- 'SECRET_KEY'
- 'SERVER_IP'
- 'SSH_KEY'
- 'SSH_USER'

3. При каждом push в ветку тесты запустятся, и, при успехе, проект автоматически деплоится на сервер.
