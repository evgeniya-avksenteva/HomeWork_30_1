# Онлайн-курсы — Проект

Приложение для сайта онлайн-обучения. Зарегистрированный пользователь может оплачивать интересующие его курсы, а также просматривать список своих курсов и уроков.

Запуск проекта через Docker Compose

Предварительные шаги

- Скопируйте файл .env.example в .env и заполните необходимые переменные окружения (например, пароли, ключи API, настройки базы данных и т.п.): cp .env.example .env
- Убедитесь, что Docker и Docker Compose установлены и запущены на вашей машине.
- Запуск

- Для запуска всех сервисов (backend, PostgreSQL, Redis, Celery, Celery Beat) выполните команду: docker-compose up --build Параметр --build гарантирует, что все образы будут пересобраны.

- Остановка

- Для остановки сервисов используйте: docker-compose down

Проверка работы сервисов

- Backend: открыть в браузере http://localhost:8000. Вы должны увидеть приветственную страницу или API документацию.
- PostgreSQL: убедитесь, что контейнер db запущен:
- docker-compose ps
- Redis: проверьте логи контейнера Redis:
docker-compose logs redis
Celery: проверьте, что воркер Celery запущен и без ошибок:
docker-compose logs celery
Celery Beat: проверьте работу планировщика задач: docker-compose logs celery-beat
